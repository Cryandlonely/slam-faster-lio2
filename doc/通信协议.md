# Bridge 通信协议文档

> 适用版本：slam-faster-lio2 bridge 节点  
> 最后更新：2025-05

---

## 1. 端口一览

| 端口 | 协议 | 方向 | 用途 |
|------|------|------|------|
| **9090** | TCP + JSON Lines | 双向 | 导航控制命令 + 状态推送 |
| **9091** | TCP + JSON Lines | 双向 | PCD 点云地图文件传输 |
| **9092** | UDP + JSON | 单向（客户端→机器人） | 摇杆速度控制 |

> **JSON Lines 格式**：每条消息为一行 JSON，以 `\n`（`0x0A`）结尾。  
> 建立 TCP 连接后，两端均使用此格式收发所有消息，不使用 HTTP 或 WebSocket。

---

## 2. TCP 9090 — 导航控制与状态

### 2.1 概述

- 客户端连接后，服务器**每 200 ms**（5 Hz）向客户端推送一条状态 JSON，无需请求。
- 客户端发送命令 JSON，服务器立即回复一条 ACK JSON。
- 所有命令 JSON 中必须包含 `"cmd"` 字段。

### 2.2 状态推送格式

服务器**主动推送**，无论客户端是否发送命令，每 200 ms 推送一次。

```json
{
  "type": "pose",
  "state": "IDLE",
  "lat": 36.661110000,
  "lon": 117.016650000,
  "yaw": 1.5708,
  "goal_lat": 36.662000000,
  "goal_lon": 117.017000000,
  "dist_to_goal": 123.4,
  "cross_track_error": 0.05,
  "battery": 25.6,
  "vx": 0.5,
  "vy": 0.0
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | 固定为 `"pose"` |
| `state` | string | 导航状态机状态，见下表 |
| `lat` | float | 当前纬度（度，9 位小数） |
| `lon` | float | 当前经度（度，9 位小数） |
| `yaw` | float | 当前航向角（弧度，地图系） |
| `goal_lat` | float | 目标点纬度（**仅在有导航目标时存在**） |
| `goal_lon` | float | 目标点经度（**仅在有导航目标时存在**） |
| `dist_to_goal` | float | 距目标点距离（米） |
| `cross_track_error` | float | 横向偏差（米） |
| `battery` | float | 电池电压（V） |
| `vx` | float | 底盘当前前进速度（m/s） |
| `vy` | float | 底盘当前横移速度（m/s） |
| `multi_nav` | bool | 多航点模式激活（**仅多航点模式时存在**） |
| `waypoint_index` | int | 当前执行的航点序号（**仅多航点模式时存在**） |
| `waypoint_total` | int | 总航点数（**仅多航点模式时存在**） |
| `paused` | bool | 导航已暂停（**仅暂停时存在**） |
| `avoiding` | bool | 正在避障绕行（**仅避障时存在**） |

#### `state` 取值说明

| 值 | 含义 |
|----|------|
| `IDLE` | 空闲，无导航任务 |
| `PLANNING` | 正在规划路径 |
| `TRACKING` | 沿路径行驶中 |
| `REACHED` | 已到达目标点 |
| `ERROR` | 导航出错（规划失败等） |

### 2.3 控制命令

#### `nav_goal` — 单点导航

机器人前往指定目标点，支持 **GPS 坐标** 和 **地图局部坐标** 两种模式。

**模式 A：GPS 坐标**

```json
{"cmd": "nav_goal", "coord_mode": "gps", "lat": 36.6621, "lon": 117.0178}
```

```json
{"cmd": "nav_goal", "coord_mode": "gps", "lat": 36.6621, "lon": 117.0178, "heading_deg": 90.0, "target_vel": 1.0}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `coord_mode` | 是 | `"gps"` 表示 GPS 模式（也兼容 `input_mode: "outdoor"`） |
| `lat` | 是 | 目标纬度（度） |
| `lon` | 是 | 目标经度（度） |
| `heading_deg` | 否 | 到达目标后的朝向（度，北为0，顺时针）；可用 `yaw`（弧度）替代 |
| `target_vel` | 否 | 目标巡航速度（m/s），0 表示使用默认速度 |

**模式 B：局部坐标（地图系）**

```json
{"cmd": "nav_goal", "x": 10.5, "y": -3.2}
```

```json
{"cmd": "nav_goal", "coord_mode": "local", "x": 10.5, "y": -3.2, "yaw": 1.5708}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `coord_mode` | 否 | `"local"` 或省略均为局部坐标模式 |
| `x` | 是 | 目标 X 坐标（米，地图系） |
| `y` | 是 | 目标 Y 坐标（米，地图系） |
| `yaw` | 否 | 到达目标后的朝向（弧度） |

**响应：**

```json
{"ack": "nav_goal"}
```

**Shell 测试示例：**

```bash
# GPS 模式，目标点纬经度
echo '{"cmd":"nav_goal","coord_mode":"gps","lat":36.6621,"lon":117.0178}' | nc 192.168.1.100 9090

# 局部坐标模式
echo '{"cmd":"nav_goal","x":5.0,"y":-2.0}' | nc 192.168.1.100 9090
```

**Python 测试示例：**

```python
import socket, json

def send_cmd(host, port, cmd_dict):
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.connect((host, port))
        s.sendall((json.dumps(cmd_dict) + '\n').encode())
        ack = s.makefile().readline()
        print("ACK:", ack.strip())

# GPS 模式
send_cmd("192.168.1.100", 9090, {
    "cmd": "nav_goal",
    "coord_mode": "gps",
    "lat": 36.6621,
    "lon": 117.0178,
    "target_vel": 1.0
})

# 局部坐标模式
send_cmd("192.168.1.100", 9090, {
    "cmd": "nav_goal",
    "x": 10.0,
    "y": -5.0,
    "yaw": 0.0
})
```

#### `nav_waypoints` — 多航点导航

发送一组航点列表，机器人依次经过每个航点。  
命令中除 `cmd` 以外的所有字段直接转发到 `/nav_waypoints` 话题。

**GPS 航点示例：**

```json
{
  "cmd": "nav_waypoints",
  "coord_mode": "gps",
  "waypoints": [
    {"lat": 36.6620, "lon": 117.0175},
    {"lat": 36.6625, "lon": 117.0180},
    {"lat": 36.6630, "lon": 117.0185}
  ],
  "target_vel": 1.0
}
```

**局部坐标航点示例：**

```json
{
  "cmd": "nav_waypoints",
  "waypoints": [
    {"x": 5.0, "y": 0.0},
    {"x": 10.0, "y": 3.0},
    {"x": 15.0, "y": 0.0}
  ]
}
```

**响应：**

```json
{"ack": "nav_waypoints"}
```

**Python 示例：**

```python
import socket, json

cmd = {
    "cmd": "nav_waypoints",
    "coord_mode": "gps",
    "waypoints": [
        {"lat": 36.6620, "lon": 117.0175},
        {"lat": 36.6625, "lon": 117.0180},
    ],
    "target_vel": 0.8
}

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect(("192.168.1.100", 9090))
    s.sendall((json.dumps(cmd) + '\n').encode())
    print(s.makefile().readline())
```

## 3. TCP 9091 — PCD 点云地图传输

### 3.1 概述

用于将机器人本地的 PCD 点云地图文件传回客户端。  
协议为 **分片拉取** 模式：先获取文件元信息，再循环请求每个数据块，直到 EOF。  
数据块以 **Base64** 编码后嵌入 JSON。

### 3.2 获取文件信息 `pcd_info`

**请求：**

```json
{"cmd": "pcd_info"}
```

**响应：**

```json
{
  "type": "pcd_info",
  "path": "/home/robot/maps/trans.pcd",
  "chunk_bytes": 65536,
  "exists": true,
  "size": 1234567,
  "mtime_ns": 1715000000000000000
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `path` | string | 机器人端文件路径（仅供参考） |
| `chunk_bytes` | int | 推荐的每次请求分片大小（字节），固定 65536 |
| `exists` | bool | 文件是否存在 |
| `size` | int | 文件总大小（字节），`exists=false` 时为 0 |
| `mtime_ns` | int | 文件最后修改时间（纳秒级 Unix 时间戳） |

文件不存在时：

```json
{"type": "pcd_info", "path": "...", "chunk_bytes": 65536, "exists": false, "size": 0, "mtime_ns": 0}
```

---

### 3.3 拉取数据块 `pcd_chunk`

**请求：**

```json
{"cmd": "pcd_chunk", "offset": 0, "length": 65536}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `offset` | 是 | 本次读取的起始字节偏移 |
| `length` | 是 | 本次请求读取的字节数（建议与 `chunk_bytes` 一致） |

**响应：**

```json
{
  "type": "pcd_chunk",
  "offset": 0,
  "length": 65536,
  "eof": false,
  "total_size": 1234567,
  "data_b64": "AAECBAUGB..."
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `offset` | int | 实际读取的起始偏移，与请求一致 |
| `length` | int | 本次实际读取到的字节数（末尾块可能小于请求长度） |
| `eof` | bool | `true` 表示已到达文件末尾，此块为最后一块 |
| `total_size` | int | 文件总大小（字节） |
| `data_b64` | string | 该分片的 Base64 编码数据 |

文件不存在时返回：

```json
{"error": "pcd_not_found"}
```

---

### 3.4 完整下载流程（Python 示例）

```python
import socket
import json
import base64
import time

HOST = "192.168.1.100"
PORT = 9091
OUTPUT_FILE = "map.pcd"

def send_recv(s, cmd_dict):
    s.sendall((json.dumps(cmd_dict) + '\n').encode())
    return json.loads(s.makefile().readline())

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect((HOST, PORT))
    f = s.makefile()  # 用于逐行读取

    # 1. 获取文件信息
    s.sendall((json.dumps({"cmd": "pcd_info"}) + '\n').encode())
    info = json.loads(f.readline())
    print(f"文件大小: {info['size']} 字节, 修改时间戳: {info['mtime_ns']}")

    if not info['exists']:
        print("地图文件不存在，请先建图！")
        exit(1)

    total_size = info['size']
    chunk_size = info['chunk_bytes']  # 65536
    offset = 0
    received = 0

    # 2. 循环拉取所有分片
    with open(OUTPUT_FILE, 'wb') as out:
        while True:
            req = {"cmd": "pcd_chunk", "offset": offset, "length": chunk_size}
            s.sendall((json.dumps(req) + '\n').encode())
            resp = json.loads(f.readline())

            if "error" in resp:
                print(f"错误: {resp['error']}")
                break

            data = base64.b64decode(resp['data_b64'])
            out.write(data)
            received += len(data)
            offset += len(data)

            progress = received / total_size * 100
            print(f"\r下载进度: {progress:.1f}% ({received}/{total_size})", end='', flush=True)

            if resp['eof']:
                break

    print(f"\n下载完成，保存至 {OUTPUT_FILE}")
```

## 4. UDP 9092 — 摇杆速度控制

### 4.1 概述

- **协议**：UDP 数据报，每包为一条 JSON，**无需建立连接**。
- **方向**：仅客户端 → 机器人（单向），机器人不回包。
- **安全机制**：若 **0.5 秒**内未收到任何 UDP 包，机器人自动发送零速命令停车。

### 4.2 数据包格式

```json
{"vx": 0.5, "vy": 0.0, "wz": 0.3}
```

| 字段 | 类型 | 单位 | 说明 |
|------|------|------|------|
| `vx` | float | m/s | 前进速度；**正值=前进，负值=后退** |
| `vy` | float | m/s | 横移速度；**正值=向左，负值=向右**（全向底盘有效，差速/履带车填 `0`） |
| `wz` | float | rad/s | 旋转角速度；**正值=逆时针（左转），负值=顺时针（右转）** |

> 字段完整性：三个字段均应存在。缺少字段时默认为 `0.0`。

### 4.3 典型操作示例

| 操作 | 发送 JSON |
|------|-----------|
| 前进 0.5 m/s | `{"vx":0.5,"vy":0,"wz":0}` |
| 后退 0.3 m/s | `{"vx":-0.3,"vy":0,"wz":0}` |
| 左转（原地） | `{"vx":0,"vy":0,"wz":0.5}` |
| 右转（原地） | `{"vx":0,"vy":0,"wz":-0.5}` |
| 前进同时左转 | `{"vx":0.4,"vy":0,"wz":0.3}` |
| 紧急停车 | `{"vx":0,"vy":0,"wz":0}` |

### 4.4 Shell 测试示例

```bash
# 前进
echo '{"vx":0.5,"vy":0.0,"wz":0.0}' | nc -u 192.168.1.100 9092

# 左转
echo '{"vx":0.0,"vy":0.0,"wz":0.5}' | nc -u 192.168.1.100 9092

# 停车
echo '{"vx":0,"vy":0,"wz":0}' | nc -u 192.168.1.100 9092
```

### 4.5 Python 持续发包示例（模拟摇杆控制）

```python
import socket
import json
import time

HOST = "192.168.1.100"
PORT = 9092
INTERVAL = 0.1  # 发包间隔（秒），建议 ≤ 0.2s，安全超时为 0.5s

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

def send_vel(vx, vy, wz):
    data = json.dumps({"vx": vx, "vy": vy, "wz": wz}).encode()
    sock.sendto(data, (HOST, PORT))

try:
    print("前进 2 秒...")
    for _ in range(int(2.0 / INTERVAL)):
        send_vel(0.5, 0.0, 0.0)
        time.sleep(INTERVAL)

    print("左转 1 秒...")
    for _ in range(int(1.0 / INTERVAL)):
        send_vel(0.0, 0.0, 0.5)
        time.sleep(INTERVAL)

    print("停车")
    send_vel(0.0, 0.0, 0.0)

finally:
    sock.close()
```

### 4.6 安全停车机制

```
客户端发包 ──→ 机器人收到 ──→ 更新最后收包时间
                                    │
                          每 50ms 看门狗检查
                                    │
                    ┌───────────────┴────────────────┐
                    │ 距上次收包 < 500ms              │ ≥ 500ms
                    │ 正常继续行驶                    │ 发送零速，机器人停车
                    └─────────────────────────────────┘
```

**影响**：
- 如果摇杆 App 崩溃、断网或暂停发包，机器人 **最多 0.5 秒后** 自动停车，不会失控。
- 停车后只需重新发包即可恢复控制，无需重连。

echo '{"cmd":"query_status"}' | nc $ROBOT_IP 9090

# 让机器人向前 3 米（局部坐标）
echo '{"cmd":"nav_goal","x":3.0,"y":0.0}' | nc $ROBOT_IP 9090

# 取消导航
echo '{"cmd":"nav_cancel"}' | nc $ROBOT_IP 9090

# 持续监听状态推送（Ctrl+C 退出）
nc $ROBOT_IP 9090 | while read line; do echo "$line" | python3 -m json.tool; done

# UDP 摇杆：前进 1 秒
for i in $(seq 1 10); do
    echo '{"vx":0.3,"vy":0,"wz":0}' | nc -u -w0 $ROBOT_IP 9092
    sleep 0.1
done
echo '{"vx":0,"vy":0,"wz":0}' | nc -u -w0 $ROBOT_IP 9092

# 查询地图文件信息
echo '{"cmd":"pcd_info"}' | nc $ROBOT_IP 9091
